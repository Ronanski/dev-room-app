Technical walkthrough · v0.14.2

Dev Room: how it works, end to end

Ipinapakita ng Dev Room ang bawat Claude Code session bilang isang character sa isang isometric na planta. Mula sa mga hook ng Claude Code hanggang sa PC app, phone app at mga awtomatikong update, bawat bahagi ay may sariling flowchart sa ibaba. Standard ISO 5807 / ANSI ang mga hugis.

PC: Tauri app (Rust) + one-file UIPhone: Capacitor Android shellServer: tiny_http, port 4317Repo: Ronanski/dev-room-app

Bakit may "kopya"Tumatanggap lang ang Claude Code ng bagong mensahe sa pagitan ng mga hakbang. Sumasagot agad ang kopya, read-only, nang hindi ginugulo ang tunay na session.

PLANO · QUALITY

Paano maiiwasan ang bugs

Karamihan ng nakita mong bugs ay lumabas lang sa totoong device: Android WebView, keyboard, totoong Claude Code sa Windows. Ito ang dagdag na mga hakbang para mahuli sila bago makarating sa iyo.

1 · Automated tests sa CI

Bawat PR, may full test

  • Server tests: lahat ng hook event at chat flow gamit ang pekeng Claude.
  • UI tests: PC, tablet portrait at landscape, phone, dark at light.
  • Hindi ma-merge kung may pumalya.
2 · Android na kondisyon

Gayahin ang tablet mo

  • Android WebView user agent at iframe tulad ng app.
  • Keyboard: lumiliit ang screen habang nagta-type.
  • Pag-rotate habang bukas ang panel.
3 · Totoong Claude Code

Gayahin ang totoong ugali

  • Late na SessionEnd, subagents, background agents, Esc.
  • Mahahabang hakbang, at mensahe habang abala.
  • Bawat bug na nakita mo, nagiging test na hindi na babalik.
4 · Diagnostics sa app

Makita agad ang dahilan

  • Health check sa Detalye: hooks, Claude Code CLI, koneksyon, version.
  • Error log na maipapadala ng isang pindot.
  • Hindi na kailangang hulaan.
